## 기술 상태와 조치

- 홈·영문·소식 목록·첫 글·robots·sitemap·소식 API 모두 HTTP 200. 홈 제목은 `리티 (Ritty) | 말하는 고양이와 함께하는 힐링 게임`, 설명도 게임 중심 유지.
- 홈/영문/목록/본문 self-canonical 및 index, follow. 공개 글 AI·비전 본문이 서버 HTML에 존재하고 구조화 데이터 및 사이트맵에 포함됨. 커버 URL도 HTTP 200.
- API의 noindex, nofollow, nosnippet은 의도된 설정으로 공개 HTML 글의 색인과 구분.
- 다른 작업에서 일본어·대만어 언어 연결이 추가되어 있음. 해당 변경을 덮어쓰지 않음.
- 로컬 `check-seo.cjs`는 최근 광고 분기 모듈 추가를 따라가지 못해 `./lib/ad-variants` 로딩 오류가 났다. 실제 모듈을 검사 로더에 전달하도록 두 줄을 추가하고 SEO 검사 통과를 확인했다. `check-news.cjs`도 통과. 제품 코드 수정이 없으므로 운영 빌드·배포를 하지 않았다.
